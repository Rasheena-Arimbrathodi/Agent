# Enterprise SLA & Support Tiers
- Standard Tier: 99.5% monthly uptime guarantee, 8-hour response time for P1 incidents.
- Enterprise Tier: 99.95% monthly uptime guarantee, 30-minute response time for P1 incidents, and a dedicated Technical Account Manager.
- Scheduled maintenance windows occur on Sundays between 02:00 and 04:00 UTC and are excluded from downtime calculations.
